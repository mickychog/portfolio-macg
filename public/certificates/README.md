# Certificados

Coloca aquí las imágenes y los PDF de certificados que se mostrarán en el portafolio.

- Imágenes recomendadas: `.webp` o `.avif`.
- Documentos: `.pdf` optimizado.
- Nombres: minúsculas, sin espacios ni acentos.
- Referencia desde TypeScript: `/certificates/nombre-del-archivo.ext`.

La configuración de cada certificado se encuentra en `lib/portfolio-data.ts`.
